# Project(4): Fluffy the Robot Pet

# How to Build such project:
Stat clamping: Store state inside a Pet_t struct, ensuring stats (food, fun, energy) are clamped between 0 and 10.

Mood state: Update status bits (HUNGRY, SAD, ASLEEP, SICK) inside updateMood() using bitwise macros based on current stat thresholds.

Visuals: Evaluate active mood bits in drawFace() to select and print the corresponding ASCII face representation.
